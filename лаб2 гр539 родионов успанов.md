13. ICMP-запросы с ПК home блокируются правилом deny ip any any, которое присутствует в конце каждого ACL.
14. В созданном ACL есть избыточное правило permit icmp 192.168.10.0 0.0.0.255 host 100.0.0.2 echo оно избыточно, потому что раньше уже присутствует permit ip 192.168.10.0 0.0.0.255 100.0.0.0 0.0.0.3 оно бесполезно потому что Первое правило разрешает любой IP-трафик административной сети к серверной подсети, включая ICMP
Поскольку ACL обрабатывается сверху вниз, ICMP-запросы от ПК admin совпадают с первым правилом. До специального правила для ICMP проверка не доходит
